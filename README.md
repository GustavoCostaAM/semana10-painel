# Painel — Semana 10 · projeto da aula (com lacunas)

Este projeto **já roda**. Ele está de propósito **incompleto**: faltam **12 lacunas** (25 marcas `⌨ LACUNA`),
que você vai escrever nas duas aulas da semana. Cada lacuna deixa o programa **funcionando e visivelmente pior**.

```
npm run dev
```
*(na sala, o `node_modules` veio junto — não rode `npm install`; em casa, `npm install` uma vez, com internet)*

O `.env` **já vem pronto** dentro do projeto (`VITE_API_URL=/api/alunos`). Se você trouxe o projeto da
semana passada, o `.env` dele é **outro** (`/alunos.json`): use este projeto da aula, ou veja as cinco armadilhas no Apêndice F da apostila.

👉 **Abra o `LACUNAS.md`, aqui do lado** (`Ctrl+Shift+V` para ler formatado). Ele tem, lacuna por lacuna, **o arquivo**,
**o lugar exato**, **o trecho que você seleciona** e **o trecho que você cola** no lugar. O porquê de cada lacuna está na
**apostila** (PDF `apostila_painel_que_diz_a_verdade_semana10`).

**Força Jovem! 🤞**
